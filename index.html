INTRODUCTION

A Little About Me

Passionate about transforming creative ideas into functional, pixel-perfect web reality.

Crafting user interfaces with care, intention, and curiosity.

I am a dedicated frontend developer with a strong foundation in modern HTML5, CSS3, and modern JavaScript. I enjoy breaking down complex problems and turning them into intuitive, visually balanced digital interfaces that delight users on every device.

My journey into web development began with a genuine fascination for how visual design connects with code. Instead of relying on heavy frameworks right away, I focused on mastering the core principles of the web: semantic structure, responsive layouts, accessibility best practices, and clean vanilla JavaScript.

When I'm not writing code or testing responsive layouts, you'll find me exploring modern design trends, refining my problem-solving skills, and experimenting with new browser APIs. I am eager to contribute my energy, attention to detail, and growth mindset to a collaborative team.

METHODOLOGY

How I Build

A structured, intentional three-step workflow that turns design ideas into reliable web experiences.

01 PHASE

1. Plan

Understand the core problem, identify the target user, sketch wireframes, and define clear structural goals before touching any code.

  • Analyze project requirements
  • Structure semantic HTML hierarchy
  • Establish typography & color tokens
02 PHASE

2. Build

Create a fully responsive interface using modern CSS and clean, modular JavaScript, focusing on mobile-first flexibility.

  • Mobile-first layout development
  • Reusable CSS custom properties
  • Maintainable, vanilla JavaScript logic
03 PHASE

3. Refine

Thoroughly test responsiveness across device widths, audit accessibility standards, optimize assets, and polish interactive details.

  • Cross-browser & viewport testing
  • Keyboard & screen reader validation
  • Performance & micro-interaction polish
